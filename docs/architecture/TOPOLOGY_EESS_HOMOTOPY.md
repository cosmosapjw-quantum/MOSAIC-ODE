# Topology, EESS, Homotopy, and Branch Roles

## Fixed separation

- topology/homology: observer and scheduler;
- EESS: reduced branch/soft hypothesis population;
- homotopy: root/path solver;
- degree/index/endgame: branch audit;
- original residual/error gate: step acceptance.

Topology may change EESS and homotopy allocation but may not certify numerical correctness.

Strict function-only homotopy is reserved for reduced branch-sensitive spaces and must log zero Jacobian/JVP/AD directional-derivative calls.
