# MOSAIC Research Loop

1. Read the scientific contract and current run state.
2. State the exact solver question and which module interactions matter.
3. Inspect primary literature/project evidence before inventing mechanisms.
4. Separate known numerical theory, project synthesis, and speculative hypotheses.
5. Validate dimensions, limits, branch assumptions, stiffness claims, and singularity semantics.
6. Use an overformalization watchdog: prove only what affects implementation or claims.
7. Preserve A+B interaction hypotheses even when isolated marginal gains are small.
8. Produce explicit next coding gates and negative-result criteria.
