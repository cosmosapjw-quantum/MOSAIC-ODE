# MOSAIC-ODE bootstrap source

This directory describes the intended use of this repository as a **boost/bootstrap source** before full product development.

The repository is intentionally more complete than a paper prototype but less frozen than a production numerical library. It contains:

- the validated Integrated V0 implementation lineage;
- a vector-native pre-product extension;
- CUDA source contracts for device-resident internal speculation;
- a combined research/coding harness;
- repository-local agent skills;
- numerical and software validation gates;
- a GitHub-ready CI skeleton.

Start with `../AGENTS.md`, `../harness/SCIENTIFIC_CONTRACT.md`, and `../docs/design/MOSAIC_ODE_INTEGRATED_PREPRODUCT_DESIGN.md`.
